## การเริ่มต้นพัฒนาในเครื่อง (Local Quickstart)

### แก้ไขข้อมูลบนหน้าเว็บ

หลังเลือกไฟล์ CSV ที่หน้า `/upload` สามารถแก้ไขค่าในตาราง เพิ่มแถว หรือลบแถวได้โดยตรง ใช้ช่องค้นหาและปุ่มเปลี่ยนหน้าเพื่อเข้าถึงข้อมูลทุกแถว จากนั้นกด **บันทึกและตรวจสอบข้อมูล** เพื่อส่งข้อมูลที่แก้แล้วไปตรวจสอบ หากพบข้อผิดพลาด ให้กด **กลับไปแก้ไขข้อมูล** แล้วบันทึกอีกครั้ง

ส่วน **กรอกข้อมูลเอง / นำเข้าไฟล์รูปแบบอื่น** ใช้โครงสร้าง DATA_CSV ทั้ง 10 ประเภท เลือกประเภทแล้วกดสร้างตารางว่าง จากนั้นเพิ่มแถวเพื่อกรอกข้อมูลได้โดยไม่ต้องมีไฟล์ต้นฉบับ วันและประเภทห้องมีรายการให้เลือก คอลัมน์บังคับแสดงเครื่องหมาย `*` โดยโครงสร้างและชื่อคอลัมน์ทางเลือกอ่านจาก backend โดยตรง

ไฟล์มาตรฐานเลือกหลายไฟล์พร้อมกันได้ ส่วนไฟล์ชื่ออื่นหรือหัวคอลัมน์ไม่ตรงให้ใช้ **นำเข้าไฟล์รูปแบบอื่น** เลือกประเภท ตรวจและจับคู่คอลัมน์ แล้วกดยืนยัน ระบบอ่าน CSV/TSV/TXT แบบ UTF-8 และตรวจตัวคั่นจุลภาค เซมิโคลอน หรือแท็บจากหัวตาราง รองรับข้อความที่มีตัวคั่นหรือขึ้นบรรทัดใหม่ภายในเครื่องหมายคำพูด หากจับคู่ไม่ชัดเจนจะให้เลือกเอง คอลัมน์บังคับต้องจับคู่ครบและห้ามใช้คอลัมน์ต้นทางซ้ำ คอลัมน์เพิ่มเติมจะยังอยู่ในตาราง การแทนที่ตารางเดิมต้องติ๊กยืนยันก่อน

ZIP ต้องแตกไฟล์ก่อน และ Excel ต้องบันทึกเป็น CSV UTF-8 ก่อนนำเข้า ฟิลด์ `start_time`, `end_time` และ `shared_student_count` เก็บเป็นข้อมูลประกอบ ไม่เปลี่ยนข้อกำหนดวัน/หมายเลขคาบของตัวจัดตาราง

การนำเข้าไฟล์รูปแบบอื่นจะแนะนำประเภทจากชื่อไฟล์และชุดหัวคอลัมน์ที่ตรงครบ หากพบหลายประเภทที่ตรงเท่ากันหรือชื่อไฟล์ขัดกับหัวคอลัมน์ จะเว้นประเภทไว้ให้เลือกเอง ก่อนยืนยันจะแสดงตัวอย่างหลังจับคู่สูงสุด 5 แถว และปิดปุ่มนำเข้าจนกว่าจะจับคู่คอลัมน์บังคับครบโดยไม่มีคอลัมน์ต้นทางซ้ำ

การเปลี่ยนข้อมูลจะล้างผลตรวจสอบและตารางสอนเดิมในหน้าจอ และการบันทึกจะสร้างชุดข้อมูลใหม่ ตัวแก้ไขบันทึกฉบับร่างอัตโนมัติในเบราว์เซอร์แยกตามบัญชีทุกครั้งที่พิมพ์ เพิ่ม/ลบแถว หรือเปลี่ยนไฟล์ จึงกู้คืนได้หลังรีเฟรชหน้า ฉบับร่างในเครื่องยังไม่ได้ส่งไปเซิร์ฟเวอร์จนกว่าจะกด **บันทึกและตรวจสอบข้อมูล** หากพื้นที่เก็บข้อมูลเต็มหรือเบราว์เซอร์ไม่อนุญาต ระบบจะแสดงข้อความแจ้ง

หน้า `/upload` ดึงชุดข้อมูลล่าสุดของบัญชีจากเซิร์ฟเวอร์ทุก 15 วินาทีขณะมองเห็นหน้า และเมื่อกลับมาที่แท็บ โดยหยุดแทนที่ข้อมูลระหว่างกำลังพิมพ์หรือมีฉบับร่างที่ยังไม่ได้ส่ง หากมีข้อมูลใหม่จะแจ้งให้ทราบโดยเก็บฉบับร่างไว้ การเชื่อมต่อขัดข้องจะลองใหม่ในรอบถัดไป ฉบับร่างใช้ได้ในเบราว์เซอร์และเครื่องเดิม ส่วนข้อมูลที่ส่งแล้วจะดึงได้จากเครื่องอื่นที่ลงชื่อเข้าใช้บัญชีเดียวกัน

ทดสอบการแก้ไขและส่ง CSV ด้วย `npm test` ในโฟลเดอร์ `frontend` (ต้องติดตั้ง dependencies ของทั้ง frontend และ Backend/server ก่อน) และสร้างไฟล์เว็บด้วย `npm run build`

### 1. ติดตั้ง Dependencies
```sh
# Backend Server
cd Backend/server
npm ci

# Frontend
cd ../../frontend
npm ci

# Python Solver Dependencies
cd ..
python -m pip install -r Backend/solver/requirements.txt
```

### 2. ตั้งค่า Environment
คัดลอกไฟล์ `Backend/.env.example` เป็น `Backend/.env` และกรอกค่าที่ต้องการ:
```sh
cp Backend/.env.example Backend/.env
```

### 3. รันระบบ (โหมด Development)
- **Terminal 1 (Backend API):**
  ```sh
  cd Backend/server
  npm run dev
  ```
- **Terminal 2 (Frontend UI):**
  ```sh
  cd frontend
  npm run dev
  ```
เปิดเบราว์เซอร์ไปที่: `http://localhost:5173` (Vite จะ proxy คำขอ `/api` ไปที่ backend port 3000 อัตโนมัติ)
